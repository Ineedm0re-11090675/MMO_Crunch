# 2026-11-08：旧 ASC 的通知别再散在角色里

上一小步把旧死亡 Tag 的清理收进了 `CharacterStateComponent`。这次顺着同一条线继续，把 Health、Mana、MoveSpeed 的属性监听，以及 Stun、Aiming、Focus 的 Tag 监听都放到这个组件里。

`CCharacter` 仍然负责“角色该怎么表现”：眩晕时走原来的玩家输入回调，瞄准时调整朝向并通知子类移动相机。组件只负责观察旧 ASC、保存 Focus 状态，再把 Stun/Aiming 的变化转给角色。监听在 ASC 初始化时绑定，`BeginPlay` 也会为客户端 AI 副本兜底；绑定后读取当前属性和已有 Tag，避免先复制到、后绑定监听而漏掉状态。

验收时要看四件事：眩晕仍会禁用／恢复玩家输入；瞄准仍会改变转向并移动相机；Focus 查询随 Tag 更新；MoveSpeed 属性变化仍能更新角色移动速度。要在服务器和客户端都看一遍。本轮只做源码检查，没有运行 UE 编译或 PIE，也没有新增蓝图配置。
